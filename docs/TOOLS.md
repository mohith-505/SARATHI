# Tools

No tools are shipped through `sarathi chat` in V0.1. Existing tool modules are development scaffolding and must not be presented as V0.1 capabilities.

V0.2 will define a tool contract with name, description, typed input/output, permission tier, execution function, verification function, timeout, audit event, and tests. Candidate first tools are system information, time, safe filesystem operations, directory creation, constrained application launch, safe terminal operations, and web search.
